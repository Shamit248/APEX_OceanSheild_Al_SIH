# APEX_OceanSheild_Al_SIH



Technical Stack

OceanShield AI is built using a combination of modern web technologies, AI/ML frameworks, geospatial tools, and cloud infrastructure to support real-time maritime surveillance and oil-spill analysis.

1) Frontend & Visualization: Next.js, React.js, Tailwind CSS, Leaflet.js, Plotly.js
2) Backend & API: FastAPI (Python), REST APIs, WebSockets, GeoJSON
3) AI & Machine Learning: PyTorch, U-Net/SegFormer for image segmentation, Random Forest/XGBoost for vessel scoring
4) Geospatial Processing: GeoPandas, GDAL, Rasterio, Shapely, NumPy, Pandas
5) Drift Modelling: Lagrangian particle tracking using ocean currents, wind, waves, and weather data
6) Maritime Data: Sentinel-1 SAR, Sentinel-2 EO, AIS, Copernicus Marine, ERA5, NOAA
7) Database & Storage: PostgreSQL, PostGIS, Redis, Cloud Object Storage
8) Deployment & DevOps: Docker, AWS/Google Cloud, CI/CD
9) Communication: RESTful APIs and WebSockets for real-time data exchange and dashboard updates
