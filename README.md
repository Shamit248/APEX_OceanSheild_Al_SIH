🚨 About

OceanShield AI is a smart maritime monitoring platform that uses satellite imagery, AI, AIS vessel data, and geospatial analysis to detect potential oil spills and identify nearby vessel associations.

🔹 Key Features
🛰️ AI-based oil spill detection from satellite imagery
🗺️ Interactive geospatial monitoring
🚢 AIS vessel tracking & correlation
🌊 Spill drift prediction
📊 Incident analytics & visualization
🚨 Centralized investigation dashboard
⚙️ Technology

Frontend: React.js, Vite, Tailwind CSS, Leaflet, Recharts
Backend: FastAPI, Python, SQLAlchemy
AI/ML: PyTorch, U-Net / SegFormer
Geospatial: GeoPandas, Rasterio, GDAL, Shapely
Data: Sentinel-1, AIS, Copernicus Marine, ERA5, NOAA

🎯 Vision

Detect → Correlate → Analyze → Respond

OceanShield AI aims to transform satellite and maritime data into actionable intelligence for faster oil-spill monitoring and investigation.
