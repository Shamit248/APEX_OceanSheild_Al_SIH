# APEX_OceanSheild_Al_SIH



Technical Stack

OceanShield AI is built using a combination of modern web technologies, AI/ML frameworks, geospatial tools, and cloud infrastructure to support real-time maritime surveillance and oil-spill analysis.

Frontend & Visualization: Next.js, React.js, Tailwind CSS, Leaflet.js, Plotly.js
Backend & API: FastAPI (Python), REST APIs, WebSockets, GeoJSON
AI & Machine Learning: PyTorch, U-Net/SegFormer for image segmentation, Random Forest/XGBoost for vessel scoring
Geospatial Processing: GeoPandas, GDAL, Rasterio, Shapely, NumPy, Pandas
Drift Modelling: Lagrangian particle tracking using ocean currents, wind, waves, and weather data
Maritime Data: Sentinel-1 SAR, Sentinel-2 EO, AIS, Copernicus Marine, ERA5, NOAA
Database & Storage: PostgreSQL, PostGIS, Redis, Cloud Object Storage
Deployment & DevOps: Docker, AWS/Google Cloud, CI/CD
Communication: RESTful APIs and WebSockets for real-time data exchange and dashboard updates
